## Прогноз оттока телеком клиентов

#### Задача: 
Разработать предсказательную модель оттока клиентов на основе данных с Kaggle.

#### Стек: 
Python, Jupyter, pandas, numpy, matplotlib, seaborn, missingno, scikit-learn.

#### Ключевые выводы
- Клиенты на оптике уходят в 2,2 раза чаще DSL. Гипотезы: цена/конкуренты/качество услуги; требует проверки с продуктом.
- Ручная оплата Electronic check - отток 45,3% против 15–17% у автоплатежей. Гипотеза: автоплатёж - маркер лояльности. Рекомендация: кампания перевода клиентов на автоплатеж
